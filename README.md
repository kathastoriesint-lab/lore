# Lore

**Worlds you can live in.** An interactive-story app — India-first, Hinglish, audience ~18–25.
Pitch: *"Stop reading stories — start living in them."* You pick a **world**, become a
character, and your choices move meters, characters DM you back (AI, in-character Hinglish,
multi-bubble like WhatsApp), a feed reacts to you, and you reach one of several endings.

Built with Next.js 16 (App Router) + React 19, Supabase (auth, data, edge functions), and
wrapped for mobile with Capacitor (iOS + Android).

---

## The two worlds

| World | You play as | Structure | Endings |
|---|---|---|---|
| **Indian Dressing Room** (cricket) | A 16-year-old Mumbai Indians prodigy | 30 situations, ~19 in-game days, 7 "Match Week" gated season, debut/semi/final results gated on Form | 5 |
| **Creator House** (reality villa) | The new 6th creator | 28 situations / 10 days, eviction nights (Day 3 & 7), TRUST-driven survival, unlockable dossiers | 4 |

Creator House cast: Ria, Kabir, Ananya, Dev, Zoya. Crush/Ally roles swap by player gender.

## Getting started

```bash
npm install
npm run dev          # Next.js dev server → http://localhost:3000
```

> The repo builds without secrets, but **won't run fully without them** (Supabase URL/keys,
> AI provider keys, MSG91 auth). See `.env.local.example` and the "What you need" section of
> [`HANDOFF.md`](HANDOFF.md).

### Common commands

```bash
npm run build            # prebuild publishes content JSON, then next build
npm test                 # run the Vitest suite
npm run publish:content  # regenerate public/content/*.json from lib/ source
npm run simulate:outcomes # simulate story outcomes
```

### Deploy

Pushing to `main` auto-deploys via Vercel. See [`HANDOFF.md`](HANDOFF.md) for details and
the current deploy/access notes.

## Tech stack

- **Framework:** Next.js 16 (App Router), React 19
- **Backend:** Supabase (Postgres, auth, edge functions)
- **AI:** in-character DM replies via the `lore-chat` edge function
- **Mobile:** Capacitor 8 (iOS + Android), local notifications
- **Testing:** Vitest + Testing Library
